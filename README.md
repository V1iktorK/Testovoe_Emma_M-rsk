# Тестовое задание: корпус контейнеровоза Emma Mærsk (без надстройки), М 1:100

**Формат сдачи — OBJ** (Wavefront). Модель сделана так, чтобы её **без настроек импортировал
человек в 3ds Max**: Z вверх, один объект, квады, раздельные нормали на острых рёбрах,
4 материала в `.mtl`.

---

## 1. Что открывать в 3ds Max

| Файл | Единицы | Длина (LOA) | Когда брать |
|---|---|---|---|
| **`Emma_Maersk_hull_1-100_mm.obj`** | миллиметры | **3977,1** | сцена в мм (обычный случай в Max) |
| `Emma_Maersk_hull_1-100_m.obj` | метры | 3,9771 | сцена, где 1 unit = 1 м |

К каждому `.obj` приложен одноимённый `.mtl` — оба файла держим рядом, имя `.mtl` не меняем.

**Импорт:** `File → Import → Import…` → тип файлов **Wavefront Object (\*.OBJ)** → выбрать `.obj`
→ в диалоге: **Scale = 1,0**, «Rescale» не включать, **оси не переворачивать**
(файл уже Z-up, как в Max). Результат: один объект `EmmaMaersk_Hull`, 4 материала
(Multi/Sub-Object), Smoothing Groups проставлены.

Если сцена в метрах, а взят `_mm.obj` — **Scale = 0,001**. Для `_m.obj` в миллиметровой сцене —
Scale = 1000.

Ориентация в файле: **+X — в нос**, **+Y — на левый борт**, **+Z — вверх**, киль в плоскости
Z = 0, начало координат — середина LOA в диаметральной плоскости.

## 4. Что смоделировано

Корпус как замкнутая оболочка (watertight), 4 согласованных поверхности:

1. **Обшивка** — лофт ватерлиний от кормы до форштевня (борт + подводная часть).
2. **Днище** — днищевая плита по обводу Z = 0 (с подъёмом к оконечностям).
3. **Палуба** — верхняя палуба с **седловатостью** (подъём к носу и корме).
4. **Транец** — транцевая плита со свойственным классу сужением книзу: ниже кромки транца
   кормовая оконечность плавно сходится к диаметральной плоскости.

Намеренные особенности обводов:

* **Бульбообразный нос** — вершина бульба на ≈11,5 м от ОЛ и ≈9,7 м впереди форштевня по КВЛ,
  скруглённая в плане и в профиле.
* **Носовая ветвь** ватерлиний: полный участок у борта и быстрый спад у форштевня.
* **Подзор кормы**: подводная кормовая оконечность сходится к ДП, транец почти вертикальный
  выше КВЛ (наклон ≈ 6 м на 17 м высоты).
* **Скула** большого радиуса — полнота мидель-шпангоута Cm = 0,948.
* 4 материала по высоте: противообрастающая окраска (ниже ВЛ), полоса КВЛ, надводный борт,
  палуба. В Max придут как Multi/Sub-Object — можно сразу перекрашивать.

винто-рулевой комплекс, якорное и швартовное устройства, палубный груз.

UV-развёртка намеренно не делалась: материалы плоские, а развёртку под конкретную текстуру
всё равно строят под задачу. Нужна — добавлю (продольная/поперечная проекция по обводу).

## 6. Как пересобрать / проверить

Вся геометрия — из скрипта, ручной лепки нет:

```powershell
# пересборка OBJ + рендеров (Blender 5.x)
blender -b --factory-startup -P scripts/hull_generator.py -- --out . --render
# только гидростатика / таблицы полуширот
blender -b --factory-startup -P scripts/hull_generator.py -- --report
# приёмочная проверка выгруженных OBJ
blender -b --factory-startup -P scripts/verify_export.py -- .
```

Добавить `--blend`, если нужна ещё и сцена Blender (по умолчанию не выгружается).

Все параметры формы (полуширота, линии форштевня/транца, полнота носовой и кормовой ветвей,
седловатость) — в словаре `PARAMS` в начале `hull_generator.py`; корпус перестраивается
под другой прототип заменой ~15 чисел.
